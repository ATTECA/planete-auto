# Planète Auto

Site vitrine et outils de vente/reprise pour Planète Auto, concessionnaire de véhicules d'occasion à Saint-Jean-de-Védas. Construit avec [Next.js](https://nextjs.org).

## Développement

```bash
pnpm install
pnpm dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) pour voir le résultat. L'application se recharge automatiquement lors des modifications de fichiers.

## Structure

- `app/` — pages et routes de l'application (App Router)
- `app/api/` — routes API (formulaires de contact et de vente/reprise)
- `components/` — composants partagés (header, footer, formulaires)
- `lib/` et `data/` — données et utilitaires liés aux véhicules
